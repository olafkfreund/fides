# Intent: Support read-only MCP sessions

## Problem

MCP exposes read and mutation tools together with no read-only mode or write annotations to inform the client.

## Proposed outcome

An operator can start MCP in read-only mode. It advertises read tools and refuses calls to mutation tools even when the caller knows their names. Write tools are annotated in normal mode, and a read-only credential is enforced by the API. Tests cover discovery, direct calls and credential authorization.

## Affected users and systems

fides-mcp, MCP clients, API authorization and installation docs.

## Constraints

Treat MCP annotations as client hints. Enforce authorization at execution and preserve a documented upgrade path for existing installations.

## Open questions

Define the read-only default for new installs and how existing deployments retain intended write access.
